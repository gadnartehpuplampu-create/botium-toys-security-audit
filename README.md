# Botium Toys Security Audit

## Project Overview

This project documents an internal cybersecurity audit performed for Botium Toys, a fictional toy company expanding its online presence internationally.

The purpose of the audit is to evaluate the organization's security posture, identify risks, review existing controls, and determine compliance gaps.

The audit follows the National Institute of Standards and Technology Cybersecurity Framework (NIST CSF).

## Audit Scope

The audit covers the entire security program at Botium Toys, including:

- IT-managed assets
- Internal processes and procedures
- Security controls
- Compliance practices

## Assets Reviewed

Assets managed by IT include:

- On-premises equipment
- Employee devices
- Remote workstations
- Storefront and warehouse inventory
- Accounting systems
- Telecommunications systems
- Database systems
- Ecommerce systems
- Inventory management systems
- Internet access
- Internal network
- Data storage and retention
- Legacy systems

## Security Frameworks Reviewed

- NIST Cybersecurity Framework (CSF)
- Payment Card Industry Data Security Standard (PCI DSS)
- General Data Protection Regulation (GDPR)
- System and Organization Controls (SOC)

## Key Findings

### Security Strengths

Implemented controls:

- Firewall protection
- Antivirus software
- Physical security locks
- CCTV surveillance
- Fire detection systems
- Data integrity controls
- GDPR breach notification process

### Security Gaps

Missing or insufficient controls:

- Least privilege access
- Separation of duties
- Encryption
- Intrusion detection system (IDS)
- Disaster recovery plan
- Critical data backups
- Centralized password management
- Strong password requirements
- Asset classification

## Risk Rating

Overall risk score:

**8/10 — High Risk**

Primary concerns:

- Unauthorized access to sensitive data
- Lack of encryption
- Insufficient recovery capabilities
- Compliance risks

## Recommendations

1. Implement least privilege access controls.
2. Encrypt customer payment information.
3. Deploy IDS monitoring.
4. Create disaster recovery procedures.
5. Establish regular backups.
6. Improve password security.
7. Maintain an updated asset inventory.
8. Strengthen compliance monitoring.
